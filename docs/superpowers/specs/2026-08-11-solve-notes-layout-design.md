# 문제 풀이 메모 레이아웃 개선 설계

## 목적

개인 문제 메모 화면에서 좌우 빈 공간을 줄이고 메모장을 넓혀, 코드와 메모를 함께 읽고 편집하기 쉽게 만든다.

## 현재 상태

- 문제 풀이 페이지의 코드 포함 컨테이너가 `max-w-5xl`로 제한되어 있다.
- 페이지 좌우 패딩은 모든 화면에서 `px-6`이다.
- 코드/메모 2열 레이아웃의 메모 영역은 큰 화면에서 320px로 고정되어 있다.

## 결정한 변경

- 코드가 있는 문제 풀이 페이지의 컨테이너를 `max-w-7xl`로 확장한다.
- 페이지 좌우 패딩을 기본 `px-4`, 작은 화면 이상에서 `sm:px-5`로 줄인다.
- 큰 화면의 코드와 메모 영역을 1:1로 나눈다.
- `lg` 미만에서는 기존처럼 코드와 메모를 한 열로 쌓는다.

## 범위와 비범위

이번 변경은 레이아웃 utility class만 수정한다. 메모 저장, 공개 설정, 줄별 메모, 데이터 조회와 API 동작은 변경하지 않는다.

## 검증 기준

- 기존 Vitest 테스트가 통과한다.
- 실제 브라우저에서 데스크톱 화면의 콘텐츠 폭과 메모장 폭이 확장된다.
- 375px, 768px, 1280px 뷰포트에서 가로 스크롤과 한국어 텍스트 잘림이 없다.
