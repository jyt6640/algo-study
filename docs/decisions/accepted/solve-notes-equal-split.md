# 문제 풀이 코드·메모 1:1 분할

## 상태

accepted

---

## 문제 상황

개인 문제 메모 화면에서 메모장이 고정 폭이면 긴 메모를 작성하거나 읽을 때 다시 좁게 느껴질 수 있다. 코드와 메모를 함께 보는 화면이므로 두 영역의 폭을 균등하게 배분할지, 메모장을 고정 폭으로 둘지 선택이 필요했다.

## 선택한 방향

큰 화면의 코드와 메모 영역을 `1:1` grid로 나눈다. `lg` 미만에서는 기존 단일 열 레이아웃을 유지한다.

## 선택 이유

### 메모 가독성

메모장은 개인 사고 과정과 코드 설명을 담는 주 영역이므로 고정 320/380px보다 충분한 작성 폭이 유리하다.

### 화면 균형

코드와 메모를 동시에 읽는 목적에 두 영역이 같은 시각적 비중을 가지며, 넓어진 페이지 공간을 한쪽만 차지하지 않는다.

## 트레이드오프

코드 영역이 고정 폭보다 넓어져 긴 코드 줄의 가로 스크롤이 줄어드는 대신, 짧은 코드에서는 메모와 코드 사이의 빈 공간이 늘어날 수 있다. 모바일에서는 공간이 부족하므로 1:1 분할을 적용하지 않는다.

## 현재 판단

이 화면은 코드 보기와 메모 작성을 동등하게 요구하므로 데스크톱 1:1 분할을 채택한다.

## 재검토 신호

- 메모 내용이 짧고 코드 가독성에 대한 불만이 반복되면 코드 영역 우선 비율을 검토한다.
- 1024px 이상 화면에서 메모장 내부 요소가 자주 줄바꿈되면 최소 열 폭 또는 반응형 비율을 재검토한다.
